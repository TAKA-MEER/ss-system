# Spec-demo — 金具認識のリアルタイム表示（本番外の道具）

[Spec.md](Spec.md) の詳細。**本番外の道具**で、依頼の流れ（[Spec.md](Spec.md) §1.1）には載らない。`SSD-1`・`SSD-6` は変えない。
**振る舞いだけを書く。**画面の実装技術・ファイル構成は詳細設計に回す。

> **2026-11-08 ユーザー決定。**決まっていない所は `未定` とし [Spec-open.md](Spec-open.md) の ID を付けた。

---

## 1. 目的

**画像認識の実現可能性を示すため、映像から吊り金具をリアルタイムで認識し、画面に表示する**（2026-11-08 ユーザー決定）。

## 2. 決まっていること

すべて 2026-11-08 ユーザー決定。

| 項目 | 決まっていること |
| --- | --- |
| 位置づけ | **本番外の道具。**依頼を受けず、盤の位置を返さない |
| 映像の入力 | **次の 3 つから選ぶ**: (1) **PC に直結した USB カメラ** ／ (2) **動画・画像フォルダ** ／ (3) **hve-system の静止画を繰り返し要求する**（**待ち**: hve-system のカメラモジュールの口ができ、繰り返し要求してよいと hve-system が答えてから。`SS-A7`） |
| hve-system の静止画を使うとき | **カメラ・昇降機は動かさない。**今向いている方を撮るだけ |
| 1280×720 でない映像 | **縦横比を保ったまま 1280×720 に収まるよう縮小・拡大し、縦横比が違うときは余白を足す（引き伸ばさない）**。小さい映像も拡大する（同じ画角の 1280×720 のカメラで撮ったときの金具の大きさに近づける。2026-11-08 ユーザー決定）。本番の推定は 1280×720 が前提（[Spec.md](Spec.md) §1.1） |
| 推定が映像に追いつかないとき | **最新のコマだけを推定し、古いコマは捨てる。1 コマの推定にかかった時間を画面に出す**（ノートパソコンの CPU での処理時間は未測定。`SS-V3`） |
| 表示するもの | **吊り金具の検出だけ。**映像の上に、金具ごとの枠・キーポイント 4 点（根元・リング中心・リング面の両端）・確信度を重ねる |
| 表示しないもの | **盤への組み立て・位置は表示しない**（カメラの姿勢と内部パラメータが要らない） |
| 確信度のしきい値 | **本番と同じ値を既定にし、起動するときに変えられる** |
| 保存 | **映像・画面を保存しない**（実物の写真を外に出さない約束を本システムが引き継ぐか（`SS-S1` の残り）とは別に、デモでは保存しない） |
| 推定 | **本番と同じ学習済みモデルで検出する**（[Spec.md](Spec.md) §1.2） |
| 動かす PC | **ノートパソコン（CPU）**（本番と同じ PC。[Spec.md](Spec.md) §5.1） |

## 3. このデモで示せないこと

このデモの結果を精度の根拠として引かない。

| 示せないこと | 理由 |
| --- | --- |
| 盤の位置・向きの精度 | 組み立てをしない（§2） |
| 実物での検出の精度 | 正解が無い（`SS-V1`） |
| 本番のカメラでの写り | モデルは hve-system のカメラ（UnitV2）の写りに合わせて合成データで学習した（[source/lifting-lug-pose.md](../source/lifting-lug-pose.md) §3・§5）。**USB カメラの映像では、本番と同じ写りにならない** |
