# Spec-tester — 依頼を手で試す道具（本番外の道具）

[Spec.md](Spec.md) の詳細。**テスト用に、人が本システムへ依頼を出して結果を見るための道具。**本番の依頼の流れ（[Spec.md](Spec.md) §1.1）は変えない。`SSD-1`・`SSD-6` は変えない。
**振る舞いだけを書く。**コマンドの名前・引数・ファイル構成は詳細設計に回す。

> **2026-11-15 ユーザー決定**（§2）。細部（§3）は実装管理担当の提案を、**2026-11-17 にユーザーがそのまま決定にした**（[Spec-open.md](Spec-open.md) `SS-A10`）。

---

## 1. 目的

**本システムの依頼の口は、ほかのシステムが使うためのもので、人がそのまま使うには向かない。テストのために、人が方向の範囲を入れて依頼し、途中経過・結果・後片付けの完了を見られるようにする**（2026-11-15 ユーザー決定）。

## 2. 決まっていること

すべて 2026-11-15 ユーザー決定。

| 項目 | 決まっていること |
| --- | --- |
| 位置づけ | **テスト用の、人向けの道具。**本番外（fk-system などの依頼する側は使わない） |
| 形 | **端末のコマンド** |
| 結果の見せ方 | **盤ごとの値の表と、上から見た図**（機体を中心に、盤の矩形と見た方向の範囲を描く） |

## 3. 細部（2026-11-17 ユーザー決定。`SS-A10`）

| 項目 | 決まっていること | 理由 |
| --- | --- | --- |
| 依頼の通り道 | **依頼する側と同じ口を通す**（別の入口を作らない）。この道具は依頼する側の 1 つとして振る舞う | 試すのが本番と同じ経路になる。本システムの中に、人のためだけの抜け道を作らない |
| 人が入れるもの | 方向の範囲（**度**。機体の前が 0°・左が正）・最大の距離・制限時間。何も入れなければ全周 | 口は rad だが、人には度が扱いやすい |
| 見せるもの | 本システムが応えているか・依頼を受けられる状態か ／ 途中経過の段 ／ 結果（終わり方の理由・盤の表・見た方向の範囲）／ 後片付けの完了（昇降機を元の高さに戻したか） | [Spec.md](Spec.md) §1.1 で返すと決めたものを、欠かさず人に見せる |
| 表の中身 | 盤ごとに、中心・機体から見た方位と距離・向き・幅・奥行き・位置と向きの標準偏差・使った吊り金具の数・正面が分かっているか。**角度は度で出す** | 巻き尺で測った位置と見比べやすい（`SS-V1` の測り方） |
| 図の中身 | 機体を中心に上から見た図。機体の前を上にする。依頼された範囲・実際に見た範囲・盤の矩形（基準の辺が分かるように）・距離の目盛り。**画像ファイルに書き出す** | 位置が合っているかを目で確かめる。実物の写真は含まないので、保存してよい |
| 依頼の前の確認 | **依頼を出す前に「昇降機とカメラが動く」と表示し、人の確認を求める。**省くことを明示したときだけ省ける | 実機では昇降機が上がる。偽の hve が相手かどうかは、この道具からは分からない |
| 取り消し | 人が途中で取り消せる。**取り消したあとも、後片付けの完了を受けるまで待ってから終わる** | 依頼した側は、後片付けの完了を受けるまで機体と昇降機を動かさない決まり（[Spec.md](Spec.md) §1.1）。人にも同じことを守らせる |
| 後片付けの完了を待つ間 | 「後片付けの完了まで、機体と昇降機を動かさないこと」を表示する | 同上 |
| 依頼できないとき | 本システムが応えない・口の版が合わない・別の依頼の最中・依頼を拒否された、のどれかを理由つきで表示し、依頼を出さずに（または出せずに）終わる | 人が原因を切り分けられるようにする |
| 状態だけ見る | 依頼を出さずに、本システムの状態だけを見ることもできる | 動かす前の確認 |
| 結果の記録 | 求めたときだけ、結果をファイルに書き出す | 精度を測るときに、あとで正解と比べる（`SS-V1`） |
| 動かさないもの | この道具は、昇降機・カメラ・機体を自分では動かさない（動かすのは依頼を受けた本システム） | `SSD-3` のまま |

## 4. この道具で示せないこと

| 示せないこと | 理由 |
| --- | --- |
| 位置・向きの精度 | 正解と比べるのは人（または別の道具）。この道具は返ってきた値を見せるだけ |
| fk-system との結合 | fk-system の代わりに人が依頼するだけで、fk-system の判断は通らない |
