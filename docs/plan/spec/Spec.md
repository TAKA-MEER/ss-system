### 1.1 求められている推定

fk-system の測定の流れ（fk-system [Spec.md](../../../../fk-system/docs/plan/spec/Spec.md) §1.1）のうち、**画像から推定するもの**。
**何を・どの形で返すかは未定**（[Spec-open.md](Spec-open.md) `SS-A1`。fk-system `FK-A1` と対）。

| 推定するもの | fk-system で使われる場面 |
| --- | --- |
| **周囲の配電盤の配置（配置図）** | 自律測定の起動直後。カメラを上げて撮る（fk-system §1.1.2） |
| **天面が映っているか** | 立会試験中の測定・自律測定の盤前。昇降機を動かしてカメラに天面が映るまで走査する（fk-system §1.1.1） |
| **天面の位置・天面中央までの距離** | 同上。画角を合わせたあとに推定する（fk-system §1.1.1） |
| **測る点の位置**（立会: 天面中央 1 点 ／ 自律: 四隅と中央の 5 点） | 同上（fk-system §1.1・`FD-7`）。点そのものを返すか、天面の位置だけ返して fk-system が点を決めるかは `SS-A1` |

### 1.2 推定の方法

**天板四隅の吊り金具を手がかりにする**（2026-10-31 ユーザー決定。fk-system 経由）。
方法と精度は検証レポート「[吊り金具による配電盤配置推定 検証レポート](https://claude.ai/artifact/A3Pz8dbXUn2srTn8NQFq2J)」（spec ではない。写さずにリンクする）。

| 項目 | 決まっていること |
| --- | --- |
| 検証の状態 | **合成データでだけ検証済み。実物の画像では未確認**（`SS-V1`） |
| 方法が前提にするもの | **ロボットの自己位置と、カメラの位置・内部パラメータ**（検証レポートの前提）。どこから得るかは未定（`SS-A2`） |
| 先行試作 | `lifting-lug-pose`（[source/README.md](../source/README.md)）。引き継ぐかは未定（`SS-S1`） |
