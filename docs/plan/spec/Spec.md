## 1. 対象

**配電盤上部を確認するロボットの画像認識を担うシステム**（2026-10-31 ユーザー決定。fk-system [Spec.md](../../../../fk-system/docs/plan/spec/Spec.md) `FD-9`）。
**fk-system（測定機能）から欲しい情報を受け取り、その情報を得るために hve-system のカメラを動かし、画像から推定した結果を返す**（2026-10-31 ユーザー決定。`SSD-3`）。
**仕様は fk-system の設計が決める。ただし fk-system 専用にせず、汎用的になるよう意識する**（2026-10-31 ユーザー決定。`SSD-4`）。

| 担当 | 範囲 | 出典 |
| --- | --- | --- |
| **本システム** | **画像認識。**fk-system から欲しい情報を受け取り、**その情報を得るために hve-system のカメラを動かして**推定し、結果を返す | 2026-10-31 ユーザー決定 |
| fk-system | 測定機能。本システムに欲しい情報を渡し、返った結果を使って判断する（人の代わりに操作の判断の一部を行う）。**本システムの仕様を決める** | fk-system [Spec.md](../../../../fk-system/docs/plan/spec/Spec.md) §1・`FD-8`・`FD-9`・`FD-10` |
| th-system | 配電盤上部を確認するロボットのうち、移動に関わるすべて | th-system [Spec.md](../../../../th-system/docs/plan/spec/Spec.md) §1 |
| hve-system | th-system の走行部に載る昇降機と上部カメラ。**カメラは本システムが動かす**（昇降機も動かすかは `SS-A5`） | hve-system [Spec.md](../../../../hve-system/docs/plan/spec/Spec.md) §1 ／ 動かすのは 2026-10-31 ユーザー決定 |

走行の指示は fk-system が出し、走行とカメラ・昇降を組み合わせる判断も fk-system が持つ（fk-system [Spec.md](../../../../fk-system/docs/plan/spec/Spec.md) §1・`FD-2`）。

### 1.1 求められている情報

fk-system の測定の流れ（fk-system [Spec.md](../../../../fk-system/docs/plan/spec/Spec.md) §1.1）のうち、**画像から推定するもの**。
fk-system はこれを欲しい情報として渡し、**本システムがカメラを動かして撮り、推定して返す**（`SSD-3`）。
**何を・どの形で返すかは未定**（[Spec-open.md](Spec-open.md) `SS-A1`。fk-system `FK-A1` と対）。

| 欲しい情報 | fk-system で使われる場面 | 得るために本システムが行うカメラの操作 |
| --- | --- | --- |
| **周囲の配電盤の配置（配置図）** | 自律測定の起動直後（fk-system §1.1.2） | カメラを上げて周囲を撮る |
| **天面の位置・天面中央までの距離** | 立会試験中の測定・自律測定の盤前（fk-system §1.1.1） | **カメラに天面が映るまで走査し、見つけたら推定に最適な画角に合わせる**（最適な画角は `SS-V2`） |
| **測る点の位置**（立会: 天面中央 1 点 ／ 自律: 四隅と中央の 5 点） | 同上（fk-system §1.1・`FD-7`）。点そのものを返すか、天面の位置だけ返して fk-system が点を決めるかは `SS-A1` | 同上 |

カメラを上げる・走査するのに昇降機も本システムが動かすかは未定（`SS-A5`。fk-system `FK-A7`）。

### 1.2 推定の方法

**天板四隅の吊り金具を手がかりにする**（2026-10-31 ユーザー決定。fk-system 経由）。
方法と精度は検証レポート「[吊り金具による配電盤配置推定 検証レポート](https://claude.ai/artifact/A3Pz8dbXUn2srTn8NQFq2J)」（spec ではない。写さずにリンクする）。

| 項目 | 決まっていること |
| --- | --- |
| 検証の状態 | **合成データでだけ検証済み。実物の画像では未確認**（`SS-V1`） |
| 方法が前提にするもの | **ロボットの自己位置と、カメラの位置・内部パラメータ**（検証レポートの前提）。画像は本システムが動かすカメラから得る（§1.1）。ほかをどこから得るかは未定（`SS-A2`） |
| 先行試作 | `lifting-lug-pose`（[source/README.md](../source/README.md)）。引き継ぐかは未定（`SS-S1`） |
